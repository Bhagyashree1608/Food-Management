# Food-Management
The Food Management System is a web application designed to simplify food order management and bill generation for restaurants. Built with PHP, HTML, and CSS, it features a secure login system, menu exploration across six cuisines (Maharashtrian, Gujarati, Rajasthani, South Indian, Bengali, and Punjabi), and seamless order placement. Bills are automatically generated with details like date, selected items, prices, and total amount, with a unique bill number for record-keeping. Users can print bills directly from the application, enhancing efficiency. The system uses phpMyAdmin for database management.
